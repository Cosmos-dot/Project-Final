# Email Header Investigation Analyzer

## Project Plan

### Project Description
The Email Header Investigation Analyzer is a cyber forensic application designed to analyze email headers and identify suspicious or malicious emails. The system validates email authentication protocols such as SPF, DKIM, and DMARC, extracts sender IP addresses, calculates a risk score, and generates investigation reports.

---

## Objectives

- Analyze raw email headers.
- Detect phishing indicators.
- Validate SPF, DKIM, and DMARC.
- Extract sender IP information.
- Generate email investigation reports.
- Provide a secure dashboard for users.
